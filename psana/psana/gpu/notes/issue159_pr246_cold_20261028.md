## Sampling and scope

Use the same accepted cold-screen harness as the pre/post-stack comparison:

- One exclusive A100 node, physical GPU 0 used by four BDs, plus one EB and Smd0.
  All four GPUs are reserved to keep the node exclusive; only one does the work.
  Node 012 was preferred but has a long-running allocation, so this submission
  lets Slurm choose another eligible node. Storage, NUMA, affinity, GPU identity,
  memory and network evidence are recorded for that node.
- Same Jungfrau run 387, 32 panels / five streams, dense raw gathering with no
  calibration or user kernel. Batch 20, depth 1, 6 GiB/BD, eight KvikIO workers,
  1 MiB tasks/groups, compatibility mode ON. No true-GDS performance claim.
- Stage five private prefixes once on node-local `/lscratch`, totaling
  335,656,487,644 bytes. Verify hashes and source stability. Never evict shared
  source files or drop the global page cache.
- Before **every timed sample**, fsync/evict only private staged files and require
  every measured prefix to be at most 1% resident. Observe post-run residency
  without eviction or a cold threshold. Staging and cache preparation are outside
  loop timing. Compilation caches are populated by separate preflights.
- Run four separate 200-event pixel/address preflights (A/B × bulk off/on).
  Then four balanced AB/BA pairs per bulk setting: **16 × 10,000-event samples**,
  n=4 per arm/setting. Verify identities, counts, budgets and MPI runtime origins
  in every sample. A must pass actual-address alignment audits before its old
  typed gather is used.
- Both arms execute byte-identical measurement helpers, including the established
  benchmark-only zero-shift reader wrapper (allocate N+1, expose N). Address
  audits are disabled in timed samples. The only harness change from the prior
  template is process-group termination if a timed MPI process hangs, plus paths
  and labels. No production API or timing boundary is changed.
- Report each sample, mean and **sample standard deviation (ddof=1)** for events/s
  and loop seconds, plus paired B/A loop changes. Keep A/B and bulk conditions
  separate. Pixel preflights are excluded. The statistics and balanced schedule
  passed standalone checks before submission.

This measures the cumulative alignment fix versus the updated target on safe
inputs. It does not measure public field-view cost. The separate field-view
benchmark, including bulk-on unaligned retirement timing with delayed consumers,
remains a gate before merge and Stage 5. Preserve the original frozen A
`90c05965c`; do not replace it with this newer matching target reference.
