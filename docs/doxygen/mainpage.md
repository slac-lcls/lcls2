# lcls2 C++ API

These pages are generated by Doxygen from the C and C++ headers (`*.h`,
`*.hh`, `*.hpp`, `*.cuh`) under `xtcdata/xtcdata`, `psalg/psalg`, `psdaq` and
`psana/psana`, as set by `INPUT` in the `Doxyfile` at the repository root.
Only headers are read; code in `.cc` and `.cpp` files is not shown.

Back to the main documentation: [lcls2 documentation home](../../index.html),
[Features](../../features/index.html), [Python API](../python/index.html).
On every C++ page, "Main Page" in the menu at the top leads back to this
page.

## How to find things

- [Namespace list](namespaces.html), [class list](annotated.html),
  [class index](classes.html), [class hierarchy](hierarchy.html) and
  [file list](files.html); the same lists are in the menu at the top and in
  the tree on the left.
- The search box at the top right searches these C++ pages. The search on the
  main documentation site does not cover C++ symbols.
